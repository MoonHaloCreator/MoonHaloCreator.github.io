报价与成本控制方案

2023-06-09

一、报价原则

1.1 基本原则

  1. 合法合规：报价符合招标文件、合同和价格法律法规要求，不串通报价、不恶意低价、不虚假报价。
  2. 真实完整：报价涵盖食材成本、采购、仓储、分拣、运输、人工、检测、保险、管理、税费等全部费用，不漏项、不低价钓鱼。
  3. 合理低价：在保证食品安全和服务质量的前提下，通过集中采购、线路优化、库存管理降低成本，让利于部队。
  4. 风险可控：充分考虑价格波动、天气、交通、应急配送等因素，预留合理风险准备，不因低价导致降标断供。
  5. 公开透明：报价依据、计价方式、调价机制在合同中明确，结算有据可查。

1.2 报价策略

本项目采用“成本导向 + 市场参考 + 竞争定位”的报价策略：

  • 以成本核算为基础，确定保本价格；
  • 以当地批发市场同期均价和政府采购价格为参考，确定合理区间；
  • 结合项目规模、配送距离、服务要求和中长期合作预期，确定最终报价；
  • 对应急配送、伴随保障等特殊服务，在合同中明确费用承担方式，不事后加价。

二、报价依据

  1. 招标文件、采购合同及补充文件；
  2. 食材品类、规格、质量等级、配送点位和时效要求；
  3. 当地农产品批发市场、商超、电商平台的同期价格；
  4. 供应商询价、历史采购价格和采购合同；
  5. 仓储、运输、人工、能耗、检测、保险等成本定额；
  6. 适用税率和财务费用；
  7. 同类项目中标价格和行业平均水平。

三、报价构成

3.1 成本构成

5 运输配送成本 车辆折旧、燃油、过路费、维修、保险 线路优化、提高装载率
6 人工成本 工资、社保、福利、培训、体检 合理定编、一人多岗

3.3 成本核算公式

  1. 单位食材成本 = 采购单价 + 采购费用分摊 + 仓储分摊 + 分拣分摊 + 运输分摊 + 检测分摊 + 损耗分摊；
  2. 毛利率 =（报价收入 - 直接成本）÷ 报价收入 × 100%；
  3. 损耗率 = 损耗数量 ÷ 入库数量 × 100%；
  4. 库存周转天数 = 平均库存金额 ÷ 日均销售成本；
  5. 吨公里成本 = 运输总成本 ÷（配送总重量 × 配送里程）；
  6. 车辆百公里油耗 = 加油量 ÷ 行驶里程 × 100。

四、计价方式与结算

4.1 计价方式

根据招标文件要求，可采用以下一种或组合方式：

  1. 固定单价：合同期内品类单价固定，适用于价格稳定、规格统一的米面粮油、调味品等；
  2. 市场下浮率：以当地批发市场同期均价为基准，按中标下浮率结算，适用于蔬菜、鲜肉等价格波动较大的品类；
  3. 随行就市 + 调价机制：按周期询价定价，设置涨跌幅触发条件和审批流程；
  4. 综合单价：将食材、包装、配送等费用合并为到货单价，便于结算和考核。

4.2 价格确认

  1. 固定单价品类在合同中列明品名、规格、单位、单价和品牌；
  2. 下浮率品类以采购人认可的批发市场或价格信息平台为采价点，每周或每两周采价一次；
  3. 采价由双方共同参与，留存采价单、照片和询价记录；
  4. 新增加品类由供应商报价，采购人审核确认后执行；
  5. 价格确认单双方签字盖章，作为结算依据。

4.3 结算方式

  1. 按合同约定的周期（月结或约定周期）结算；
  2. 结算依据包括订单、配送单、验收单、退换记录和价格确认单；
  3. 客服组编制结算清单，采购人核对无误后开具发票；
  4. 发票内容与实际交易一致，不得虚开、代开；
  5. 结算差异在 5 个工作日内核对处理，多退少补。

五、成本控制措施

5.1 采购成本控制

  1. 集中采购：合并各伙食单位需求，形成批量订单，提高议价能力；
  2. 比价采购：每个品类至少 3 家供应商询价，择优采购；
  3. 基地直采：对蔬菜、水果等鲜活农产品，与主产区、合作社、基地建立直采渠道，减少中间环节；
  4. 季节性采购：优先采购当季品种，降低反季节采购成本；
  5. 价格监测：建立价格台账，跟踪批发市场价格，发现异常及时调整；
  6. 供应商考核：将价格、质量、交货期纳入考核，实行优胜劣汰。

5.2 仓储成本控制

  1. 合理规划库容，提高库房利用率；
  2. 实行先进先出，减少临期和过期损耗；
  3. 设置安全库存和补货点，避免缺货和积压；
  4. 每日记录温湿度，降低制冷能耗和变质风险；
  5. 定期盘点，做到账物相符，及时发现差异；
  6. 周转筐、托盘循环使用，降低耗材成本。

5.3 配送成本控制

  1. 优化配送线路，减少空驶和迂回；
  2. 提高装载率，合理搭配轻重货和大小点；
  3. 合并相近点位、错峰配送，降低重复运输；
  4. 加强车辆保养，保持胎压正常，降低油耗；
  5. 执行《车辆管理制度》油耗考核，奖节罚超；
  6. 长途配送合理安排休息和加油，降低过路费和维修费。

5.4 人工成本控制

  1. 按业务量合理定编，避免人浮于事；
  2. 培养多能工，实行一人多岗、峰谷调配；
  3. 优化排班，减少加班和无效等待；
  4. 通过信息化减少手工台账和重复录入；
  5. 控制人员流失，降低招聘和培训成本。

5.5 损耗控制

  1. 采购环节严把质量关，减少不合格品入库；
  2. 仓储环节控制温湿度，防止腐烂、霉变、冻伤；
  3. 分拣环节轻拿轻放，减少机械损伤；
  4. 配送环节控制温度和时间，防止断链；
  5. 建立损耗台账，按品类、环节分析原因，制定改进措施；
  6. 对临期食材提前预警，优先出库或协商处理。

5.6 管理成本控制

  1. 实行预算管理，严控办公、差旅、招待费用；
  2. 推行无纸化办公，降低单据和打印成本；
  3. 信息系统集中管理，避免重复建设；
  4. 采购、库存、配送数据共享，减少重复劳动；
  5. 定期开展成本分析，发现异常及时纠偏。

六、价格调整机制

6.1 触发条件

  1. 合同约定的调价周期到期；
  2. 主要食材市场价格连续【】个采价周期涨跌幅超过【】%；
  3. 国家政策、税收、运输成本发生重大变化；
  4. 不可抗力导致采购、运输成本显著上升；
  5. 采购人新增或变更品种、规格、配送要求。

6.2 调整流程

  1. 任一方提出调价申请，附市场价格依据、成本测算和影响说明；
  2. 双方共同采价、核价，形成调价方案；
  3. 调价方案经采购人审批后，签订补充协议或价格确认单；
  4. 调价自批准之日起执行，不追溯已结算订单；
  5. 调价资料归档备查。

6.3 调价公式

采用市场联动调价时，按以下公式计算：

调整后单价 = 基准单价 ×（1 +（当期市场均价 - 基期市场均价）÷ 基期市场均价 × 调整系数）

其中：

  • 基准单价为合同约定单价；
  • 当期市场均价为双方共同采价确认的均价；
  • 基期市场均价为合同签订时的市场均价；
  • 调整系数由合同约定，原则上不超过 1；
  • 涨跌幅未达到触发条件的不调整。

6.4 价格承诺

  1. 合同期内不无故涨价、不变相涨价；
  2. 不降低规格、等级、品牌和净含量；
  3. 不将包装、运输、装卸等费用转嫁给收货单位；
  4. 市场价格下降时，按约定机制同步下调；
  5. 应急配送、伴随保障不额外加价，合同另有约定的除外。

七、应急与让利

7.1 应急费用

  1. 日常应急加送、补货，原则上不收取额外配送费；
  2. 伴随保障产生的人员、车辆、仓储和运输费用，按合同约定或双方协商结算；
  3. 不可抗力导致的绕行、滞留费用，双方本着公平合理原则分担；
  4. 应急费用留存凭证，据实结算，不虚报、不多报。

7.2 让利措施

  1. 对批量采购、长期合作、淡季储备给予价格优惠；
  2. 对部队节日保障、重大任务保障，优先保障并按约定让利；
  3. 免费提供食品安全培训、快检服务和追溯查询；
  4. 免费提供周转筐、保温箱等配送器具的使用；
  5. 对采购人提出的合理化建议，免费提供方案支持。

八、成本核算与监督

8.1 成本核算

  1. 建立分品类、分客户、分车辆的成本核算台账；
  2. 每月核算采购成本、仓储成本、配送成本、人工成本和损耗；
  3. 对比预算与实际，分析差异原因；
  4. 每季度开展项目盈亏分析，提出改进措施；
  5. 成本数据真实完整，不得弄虚作假。

8.2 内部监督

  1. 采购、验收、付款岗位分离，相互制约；
  2. 采购价格、供应商选择实行集体决策和审批；
  3. 财务定期抽查采购发票、验收单和结算单；
  4. 审计部门每年开展一次项目专项审计；
  5. 发现违规行为严肃处理。

8.3 外部监督

  1. 接受采购人和部队后勤部门的价格核查；
  2. 提供采购凭证、价格依据和成本测算资料；
  3. 配合市场监管、税务等部门检查；
  4. 对价格异议及时说明，协商解决。

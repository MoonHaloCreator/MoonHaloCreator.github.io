报价与成本控制方案

2023-06-09

一、报价原则

1.1 基本原则

  1. 合法合规：报价符合招标文件、合同和价格法律法规要求，不串通报价、不恶意低价、不虚假报价。
  2. 真实完整：报价涵盖食材成本、采购、仓储、分拣、运输、人工、检测、保险、管理、税费等全部费用，不漏项、不低价钓鱼。
  3. 合理低价：在保证食品安全和服务质量的前提下，通过集中采购、线路优化、库存管理降低成本，让利于部队。
  4. 风险可控：充分考虑价格波动、天气、交通、应急配送等因素，预留合理风险准备，不因低价导致降标断供。
  5. 公开透明：报价依据、计价方式、调价机制在合同中明确，结算有据可查。

1.2 报价策略

本项目采用“成本导向 + 市场参考 + 竞争定位”的报价策略：

  • 以成本核算为基础，确定保本价格；
  • 以当地批发市场同期均价和政府采购价格为参考，确定合理区间；
  • 结合项目规模、配送距离、服务要求和中长期合作预期，确定最终报价；
  • 对应急配送、伴随保障等特殊服务，在合同中明确费用承担方式，不事后加价。

二、报价依据

  1. 招标文件、采购合同及补充文件；
  2. 食材品类、规格、质量等级、配送点位和时效要求；
  3. 当地农产品批发市场、商超、电商平台的同期价格；
  4. 供应商询价、历史采购价格和采购合同；
  5. 仓储、运输、人工、能耗、检测、保险等成本定额；
  6. 适用税率和财务费用；
  7. 同类项目中标价格和行业平均水平。

3.3 成本核算公式

  1. 单位食材成本 = 采购单价 + 采购费用分摊 + 仓储分摊 + 分拣分摊 + 运输分摊 + 检测分摊 + 损耗分摊；
  2. 毛利率 =（报价收入 - 直接成本）÷ 报价收入 × 100%；
  3. 损耗率 = 损耗数量 ÷ 入库数量 × 100%；
  4. 库存周转天数 = 平均库存金额 ÷ 日均销售成本；
  5. 吨公里成本 = 运输总成本 ÷（配送总重量 × 配送里程）；
  6. 车辆百公里油耗 = 加油量 ÷ 行驶里程 × 100。

四、计价方式与结算

4.1 计价方式

根据招标文件要求，可采用以下一种或组合方式：

  1. 固定单价：合同期内品类单价固定，适用于价格稳定、规格统一的米面粮油、调味品等；
  2. 市场下浮率：以当地批发市场同期均价为基准，按中标下浮率结算，适用于蔬菜、鲜肉等价格波动较大的品类；
  3. 随行就市 + 调价机制：按周期询价定价，设置涨跌幅触发条件和审批流程；
  4. 综合单价：将食材、包装、配送等费用合并为到货单价，便于结算和考核。

4.2 价格确认

  1. 固定单价品类在合同中列明品名、规格、单位、单价和品牌；
  2. 下浮率品类以采购人认可的批发市场或价格信息平台为采价点，每周或每两周采价一次；
  3. 采价由双方共同参与，留存采价单、照片和询价记录；
  4. 新增加品类由供应商报价，采购人审核确认后执行；
  5. 价格确认单双方签字盖章，作为结算依据。

4.3 结算方式

  1. 按合同约定的周期（月结或约定周期）结算；
  2. 结算依据包括订单、配送单、验收单、退换记录和价格确认单；
  3. 客服组编制结算清单，采购人核对无误后开具发票；
  4. 发票内容与实际交易一致，不得虚开、代开；
  5. 结算差异在 5 个工作日内核对处理，多退少补。

五、成本控制措施

5.1 采购成本控制

  1. 集中采购：合并各伙食单位需求，形成批量订单，提高议价能力；
  2. 比价采购：每个品类至少 3 家供应商询价，择优采购；
  3. 基地直采：对蔬菜、水果等鲜活农产品，与主产区、合作社、基地建立直采渠道，减少中间环节；
  4. 季节性采购：优先采购当季品种，降低反季节采购成本；
  5. 价格监测：建立价格台账，跟踪批发市场价格，发现异常及时调整；
  6. 供应商考核：将价格、质量、交货期纳入考核，实行优胜劣汰。

5.2 仓储成本控制

  1. 合理规划库容，提高库房利用率；
  2. 实行先进先出，减少临期和过期损耗；
  3. 设置安全库存和补货点，避免缺货和积压；
  4. 每日记录温湿度，降低制冷能耗和变质风险；
  5. 定期盘点，做到账物相符，及时发现差异；
  6. 周转筐、托盘循环使用，降低耗材成本。

5.3 配送成本控制

  1. 优化配送线路，减少空驶和迂回；
  2. 提高装载率，合理搭配轻重货和大小点；
  3. 合并相近点位、错峰配送，降低重复运输；
  4. 加强车辆保养，保持胎压正常，降低油耗；
  5. 执行《车辆管理制度》油耗考核，奖节罚超；
  6. 长途配送合理安排休息和加油，降低过路费和维修费。

5.4 人工成本控制

  1. 按业务量合理定编，避免人浮于事；
  2. 培养多能工，实行一人多岗、峰谷调配；
  3. 优化排班，减少加班和无效等待；
  4. 通过信息化减少手工台账和重复录入；
  5. 控制人员流失，降低招聘和培训成本。

5.5 损耗控制

  1. 采购环节严把质量关，减少不合格品入库；
  2. 仓储环节控制温湿度，防止腐烂、霉变、冻伤；
  3. 分拣环节轻拿轻放，减少机械损伤；
  4. 配送环节控制温度和时间，防止断链；
  5. 建立损耗台账，按品类、环节分析原因，制定改进措施；
  6. 对临期食材提前预警，优先出库或协商处理。

5.6 管理成本控制

  1. 实行预算管理，严控办公、差旅、招待费用；
  2. 推行无纸化办公，降低单据和打印成本；
  3. 信息系统集中管理，避免重复建设；
  4. 采购、库存、配送数据共享，减少重复劳动；
  5. 定期开展成本分析，发现异常及时纠偏。

六、价格调整机制

6.1 触发条件

  1. 合同约定的调价周期到期；
  2. 主要食材市场价格连续【】个采价周期涨跌幅超过【】%；
  3. 国家政策、税收、运输成本发生重大变化；
  4. 不可抗力导致采购、运输成本显著上升；
  5. 采购人新增或变更品种、规格、配送要求。

6.2 调整流程

  1. 任一方提出调价申请，附市场价格依据、成本测算和影响说明；
  2. 双方共同采价、核价，形成调价方案；
  3. 调价方案经采购人审批后，签订补充协议或价格确认单；
  4. 调价自批准之日起执行，不追溯已结算订单；
  5. 调价资料归档备查。

6.3 调价公式

采用市场联动调价时，按以下公式计算：

调整后单价 = 基准单价 ×（1 +（当期市场均价 - 基期市场均价）÷ 基期市场均价 × 调整系数）

其中：

  • 基准单价为合同约定单价；
  • 当期市场均价为双方共同采价确认的均价；
  • 基期市场均价为合同签订时的市场均价；
  • 调整系数由合同约定，原则上不超过 1；
  • 涨跌幅未达到触发条件的不调整。

6.4 价格承诺

  1. 合同期内不无故涨价、不变相涨价；
  2. 不降低规格、等级、品牌和净含量；
  3. 不将包装、运输、装卸等费用转嫁给收货单位；
  4. 市场价格下降时，按约定机制同步下调；
  5. 应急配送、伴随保障不额外加价，合同另有约定的除外。

七、应急与让利

7.1 应急费用

  1. 日常应急加送、补货，原则上不收取额外配送费；
  2. 伴随保障产生的人员、车辆、仓储和运输费用，按合同约定或双方协商结算；
  3. 不可抗力导致的绕行、滞留费用，双方本着公平合理原则分担；
  4. 应急费用留存凭证，据实结算，不虚报、不多报。

7.2 让利措施

  1. 对批量采购、长期合作、淡季储备给予价格优惠；
  2. 对部队节日保障、重大任务保障，优先保障并按约定让利；
  3. 免费提供食品安全培训、快检服务和追溯查询；
  4. 免费提供周转筐、保温箱等配送器具的使用；
  5. 对采购人提出的合理化建议，免费提供方案支持。

八、成本核算与监督

8.1 成本核算

  1. 建立分品类、分客户、分车辆的成本核算台账；
  2. 每月核算采购成本、仓储成本、配送成本、人工成本和损耗；
  3. 对比预算与实际，分析差异原因；
  4. 每季度开展项目盈亏分析，提出改进措施；
  5. 成本数据真实完整，不得弄虚作假。

8.2 内部监督

  1. 采购、验收、付款岗位分离，相互制约；
  2. 采购价格、供应商选择实行集体决策和审批；
  3. 财务定期抽查采购发票、验收单和结算单；
  4. 审计部门每年开展一次项目专项审计；
  5. 发现违规行为严肃处理。

8.3 外部监督

  1. 接受采购人和部队后勤部门的价格核查；
  2. 提供采购凭证、价格依据和成本测算资料；
  3. 配合市场监管、税务等部门检查；
  4. 对价格异议及时说明，协商解决。

项目进场与交接方案

2023-06-08

一、进场目标与原则

1.1 进场目标

确保项目合同签订后，人员、车辆、仓储、货源、系统和证照在规定时间内到位，实现与原有保障体系平稳衔接，做到“不断供、不降标、不泄密、不混乱”。

1.2 基本原则

  1. 提前介入：合同签订前即成立进场筹备组，提前熟悉部队需求、配送点位和保障要求。
  2. 平稳过渡：设置试运行期，逐步接管订单和配送任务，避免交接期间出现断供。
  3. 责任到人：每项准备工作明确责任人、完成时限和验收标准。
  4. 合规进场：人员审查、证照备案、车辆检查、保密教育同步完成。
  5. 应急兜底：预置备用人员、车辆、货源和临时仓储，出现问题立即补位。

二、进场组织与职责

2.1 进场领导小组

由公司分管负责人任组长，项目经理任副组长，成员包括采购、质检、仓储、配送、财务、人事和客服负责人。领导小组负责进场计划审批、资源调配、重大问题协调和进场验收。

三、进场准备工作

3.1 合同与备案

  1. 完成合同签订、履约保证金缴纳和保险投保；
  2. 向采购人提交营业执照、食品经营许可证、法定代表人证明、授权委托书、项目人员名单等备案资料；
  3. 按部队要求办理人员、车辆出入证件和保密审批手续；
  4. 明确合同联系人、应急联系人和 24 小时值班电话。

3.2 人员准备

  1. 按项目规模配置项目经理、食品安全员、采购员、质检员、仓管员、分拣员、调度员、驾驶员、配送员和客服专员；
  2. 关键岗位人员提前到岗，熟悉项目情况和部队要求；
  3. 所有从业人员取得有效健康证明，驾驶员取得相应驾驶证和从业资格证；
  4. 进场前完成食品安全、保密纪律、服务规范、应急流程和车辆安全培训；
  5. 签订劳动合同、保密承诺书和食品安全责任书。

3.3 车辆准备

  1. 按配送需求配置冷藏车、常温车和备用车；
  2. 完成车辆年检、保险、行驶证和道路运输相关证件核验；
  3. 安装 GPS、车厢温度记录仪、灭火器、警示标志和防滑设施；
  4. 完成车辆清洁、消毒和制冷设备调试；
  5. 建立车辆档案和驾驶员档案，执行《车辆管理制度》。

3.4 仓储准备

  1. 落实常温库、冷藏库、冷冻库和分拣区，面积和容积满足项目需求；
  2. 完成库房清洁、消毒、防鼠防虫和通风改造；
  3. 配置货架、托盘、周转筐、温湿度记录仪、检验设备和消防器材；
  4. 划分待检区、合格区、不合格区、退货区和留样区；
  5. 完成库房验收和温湿度连续测试，确保达到储存要求。

3.5 货源准备

  1. 完成供应商准入审核，建立合格供应商名录；
  2. 每个大类至少确定 2 家供应商，重点品种确定应急供应商；
  3. 与供应商签订供货协议，明确质量标准、价格、配送时限和违约责任；
  4. 提前组织首批货源，常用品种保持 3—5 日安全库存；
  5. 完成首批食材索证索票和检测报告收集。

3.6 信息系统准备

  1. 建立订单、库存、配送、追溯和结算台账；
  2. 完成配送点位、伙食单位、联系人、收货时间等基础数据初始化；
  3. 完成与采购人系统的数据对接或接口测试；
  4. 配置权限、备份和保密措施；
  5. 准备纸质单据作为系统故障时的备用手段。

3.7 证照、保险与制度准备

  1. 营业执照、食品经营许可证、检验检测报告等资质文件齐全有效；
  2. 投保食品安全责任险、车辆保险和雇主责任险；
  3. 食品安全、车辆管理、仓储管理、配送服务、应急管理、保密管理等制度上墙；
  4. 建立台账模板、交接单、验收单、回单和异常记录表。

交接双方共同填写《项目交接清单》，内容包括交接日期、交接项目、数量、状态、存在问题、交接人和监交人签字。清单一式三份，交接双方和采购人各执一份。

4.4 交接纪律

  1. 交接在采购人指定人员和监交人见证下进行；
  2. 库存盘点须现场清点，不得仅凭账面数据交接；
  3. 临期、变质、不合格食材单独登记，明确处置责任；
  4. 交接期间不得中断正常配送，出现争议先保障、后协商；
  5. 涉及部队信息的资料按保密要求移交，不得私自留存或外传。

五、首日与试运行保障

5.1 首配演练

正式配送前 1—3 日组织全流程演练，模拟订单接收、采购备货、分拣复核、装车配送、交接验收和异常处置；演练覆盖全部配送点位和重点品种，发现问题立即整改。

5.2 首日保障

  1. 项目经理、调度员、质检员提前到岗，现场指挥；
  2. 首日配送安排双人押车，关键点位安排管理人员跟车；
  3. 备用车辆和备用人员现场待命；
  4. 客服组全程跟踪，每 2 小时汇总一次配送进度；
  5. 首日结束后召开复盘会，记录问题、明确整改责任人和时限。

5.3 试运行期

试运行期原则上为 30 日，重点验证：

  • 订单接收和确认是否顺畅；
  • 货源质量、规格和价格是否稳定；
  • 分拣、装载和配送时效是否达标；
  • 交接验收和回单流程是否规范；
  • 冷链温度和追溯记录是否完整；
  • 人员、车辆和应急保障是否满足要求。

试运行期间实行日报告、周总结，发现问题即时整改；重大问题 24 小时内向采购人书面报告。

5.4 试运行验收

试运行结束后，项目部提交试运行总结报告，内容包括配送量、准时率、合格率、投诉处理、问题整改和资源投入情况；配合采购人开展验收，验收合格后转入正式运行。

六、系统与数据交接

6.1 数据初始化

  1. 导入伙食单位、配送地址、联系人、收货时间、品种规格和价格数据；
  2. 导入库存期初数据，确保账物一致；
  3. 设置订单、审核、配送、验收、结算等流程权限；
  4. 建立数据备份和恢复机制。

6.2 数据安全

  1. 项目数据仅限授权人员访问，实行账号实名和权限分级；
  2. 涉军数据不得存储在个人设备或公网网盘；
  3. 数据导出、打印和传递须经项目经理审批；
  4. 项目结束后按采购人要求移交或销毁数据，不得私自留存。

6.3 故障应对

系统故障时立即启用手工订单、纸质配送单和电话确认流程，确保配送不中断；信息组 30 分钟内响应，2 小时内恢复或启用备用系统，故障情况记录备案。

八、退出交接

合同期满、终止或更换供应商时，按采购人要求做好退出交接：

  1. 提前 30 日制定退出交接计划，报采购人批准；
  2. 配合新供应商熟悉点位、订单、路线和收货要求；
  3. 清理库存，处理临期和退货食材，结清货款；
  4. 移交订单、验收、追溯和结算资料；
  5. 移交周转筐、托盘、设备等物资；
  6. 撤出人员、车辆和临时设施，清理现场；
  7. 按保密要求销毁或移交涉军资料；
  8. 完成退出交接清单签字确认。

九、保密与纪律

  1. 进场人员一律接受保密教育，签订保密承诺书；
  2. 不得拍摄、记录、传播部队营区、装备、人员和任务信息；
  3. 不得向无关人员透露配送点位、时间、品种和数量；
  4. 不得私自留存、复制、带出涉军资料；
  5. 违反保密规定的人员立即调离，情节严重的依法追究责任；
  6. 进场和退出过程接受采购人和部队相关部门监督检查。

配送服务方案

一、配送服务目标与原则

1.1 服务目标

围绕“安全、准时、准确、保鲜、保密”五项要求，确保部队伙食单位在约定时间收到符合质量标准的食品原料。

指标 目标值
配送准时率 不低于 99%
品种、数量准确率 100%
冷链温度达标率 100%
交接单签收完整率 100%
紧急加单响应时间 30 分钟内确认，2 小时内送达（市区）
投诉响应时间 30 分钟内
配送服务满意度 不低于 95%

1.2 服务原则

  1. 计划配送与应急配送相结合：日常按计划配送，紧急情况启动应急配送。
  2. 前送保障与伴随保障相衔接：100 公里范围内以前送为主，超出范围或部队移防时转入伴随保障。
  3. 专车专送、双人双锁：配送车辆专用，驾驶员与配送员共同负责，确保运输环节安全。
  4. 全程温控、全程记录：冷藏冷冻食材从出库到交接全程温度可控、记录可查。
  5. 服从部队指挥：配送时间、路线、交接方式以部队要求为准，特殊情况及时报告。

二、配送服务范围与模式

2.1 服务范围

服务对象为项目约定的部队伙食单位，配送地址包括营区、训练场、任务区域和临时保障点位。具体地址、联系人、收货时间以采购人提供的清单为准，项目部建立配送点位台账并动态更新。

2.2 配送模式

模式 适用条件 组织方式 响应要求
前送保障 距配送中心 100 公里范围内 配送中心直接配送到各伙食单位 按约定时间准时到达
伴随保障 超出 100 公里或部队移防、演训、抢险救灾 在任务区域设置临时保障点，跟随部队实施保障 接到命令后按协议时限启动
应急配送 临时加单、断供、车辆故障、道路中断 备用车辆、备用人员、应急货源 30 分钟内确认，尽快送达
节假日保障 春节、国庆等节假日 提前备货、值班配送 按节日保障计划执行

2.3 前送保障

前送保障执行“订单—备货—分拣—装车—配送—交接”标准流程。配送中心根据各伙食单位距离、道路状况和收货时间，编制每日配送计划，合理确定发车时间，确保提前 10—15 分钟到达交接点。

2.4 伴随保障

部队离开驻地执行任务时，按照《应对伴随保障方案》启动伴随保障：

  1. 组建伴随保障组，明确负责人、采购员、驾驶员、配送员和通信联络员；
  2. 在任务区域开发临时供应商和采购渠道，建立临时周转库；
  3. 配置伴随保障车辆和应急物资，随部队行动实施“零距离”保障；
  4. 建立临时通信联络机制，每日报告库存、需求和配送情况；
  5. 任务结束后做好物资清点、账款结算和资料归档。

2.5 应急配送

出现临时加单、货源短缺、车辆故障、道路中断等情况时，调度员立即启动应急配送：

  • 启用备用车辆和备用驾驶员；
  • 启用应急供应商和替代品种；
  • 调整线路或采用接力配送；
  • 道路无法通车时，组织人员徒步或使用小型车辆前送；
  • 及时向采购人报告进度，必要时请求部队协助。

三、订单受理与需求管理

3.1 订单渠道

通过采购人指定的电话、传真、即时通信或信息系统接收订单，实行“专人受理、双人核对、书面确认”。订单内容包括：伙食单位、品名、规格、数量、质量要求、配送地址、收货时间、联系人及特殊说明。

3.2 订单时限

订单类型 接收截止时间 配送时限
常规订单 配送前一日约定时间 次日约定时间送达
临时加单 当日约定截止时间 市区 2 小时内，郊区 4 小时内
紧急订单 随时接收 按部队要求，最短时限送达
节日订单 节前 3—5 日 按节日保障计划送达

3.3 订单变更

订单确认后，采购人需变更品种、数量或时间的，客服组立即通知采购、仓储和配送环节；已采购且无法退换的食材，双方协商处理，不得将损失转嫁给部队。

3.4 需求预测

项目部根据部队人数、食谱计划、季节变化、训练强度和任务安排，建立需求预测模型；每周与采购人沟通下周需求，每月分析品种和数量变化，提前储备常用食材和应急物资。

四、备货、分拣与装载

4.1 备货

采购组按订单组织货源，优先使用库存，库存不足时向合格供应商下单；对蔬菜、鲜肉、禽蛋、豆制品等鲜活食材，安排当日采购、当日配送，缩短周转时间。

4.2 分拣

  1. 分拣前检查分拣区、周转筐、台面和工具清洁消毒情况；
  2. 按伙食单位、品类、规格、数量分拣，生熟分开、荤素分开、成品与原料分开；
  3. 剔除病斑、腐烂、破损、异物和不符合规格的食材；
  4. 分拣后称重复核，误差控制在约定范围内；
  5. 粘贴标签，注明品名、规格、数量、批次、生产日期、保质期、收货单位。

4.3 包装与标识

定型包装食品保持原包装完整，不得拆包散装；散装食材使用食品级容器或包装材料，密封防漏；冷藏冷冻食材使用保温箱或冷藏车装载，避免温度波动。

4.4 装车

装车顺序遵循“先卸后装、重不压轻、生熟分开、冷链优先”：

  1. 按配送点卸货顺序逆向装车，减少现场翻找；
  2. 重货在下、轻货在上，液体与干货隔离，防止压损和污染；
  3. 冷藏、冷冻食材最后装车、最先卸货，缩短开门时间；
  4. 装车完毕由驾驶员和配送员共同核对品种、数量、单据，确认车门锁闭。

4.5 双人双锁

执行《车辆管理制度》双人双锁规定：每车配置驾驶员 1 名、配送员 1 名，车厢钥匙和锁具分别保管，两人同时到场方可开启车厢；交接过程中不得脱离视线，防止食材被污染、调换或丢失。

五、运输与线路管理

5.1 线路规划

调度员根据配送点位、道路状况、交通管制、天气和收货时间，编制主线路和备选线路；线路规划遵循“由近及远、循环配送、避开拥堵、留有余量”的原则，确保准时到达。

5.2 车辆与温控

  1. 配送车辆出车前执行晨检，检查制动、转向、灯光、轮胎、油水电、车门锁具和制冷设备；
  2. 冷藏车出车前预冷至规定温度，装车过程减少开门时间；
  3. 车厢内温度按食材要求控制：冷藏 0—8℃，冷冻 -18℃以下；
  4. 随车配置温度记录仪，记录全程温度，交接时向收货人展示。

5.3 在途监控

车辆安装 GPS，调度员实时查看位置、速度和行驶轨迹；发现偏离线路、长时间停留、异常低速等情况，立即联系驾驶员核实；驾驶员不得擅自改变线路、搭载无关人员或中途卸货。

5.4 时效控制

  1. 发车前预留交通拥堵、检查登记、装卸排队时间；
  2. 长途配送按规定安排驾驶员休息，连续驾驶不超过 4 小时；
  3. 遇交通管制、道路施工、恶劣天气，提前报告并调整线路；
  4. 预计延误超过 30 分钟的，提前通知收货单位和项目部，说明原因和预计到达时间。

5.5 交接地点

交接地点以采购人指定位置为准，一般设在营区指定收货区或任务区域临时保障点；车辆按指定位置停放，不得堵塞通道、不得进入非指定区域。

六、交接验收与回单

6.1 交接流程

  1. 配送员出示配送单、检验检疫证明和温度记录；
  2. 双方共同清点品种、规格、数量；
  3. 收货人检查外观、包装、气味、温度和保质期；
  4. 验收合格后双方签字确认，配送员交付回单；
  5. 需要入库的，协助搬运至指定位置，按先进先出摆放。

6.2 验收内容

验收项 验收要求
品种规格 与订单一致，无擅自替换
数量 与订单一致，称重误差在约定范围
外观 新鲜、无腐烂、无霉变、无虫害、无异物
包装 完整、清洁、标识清晰、无破损渗漏
温度 冷藏 0—8℃，冷冻 -18℃以下
证票 检验检疫证明、检测报告与批次相符
保质期 剩余保质期符合约定要求

6.3 异常处理

  1. 品种、数量不符的，现场核对订单和配送单，能补送的立即补送；
  2. 质量不合格的，立即隔离封存，拍照留证，安排退换；
  3. 温度超标的，收货人有权拒收，配送员立即报告调度员；
  4. 现场无法认定的，双方共同取样送检，以检测结果为准；
  5. 所有异常填写《配送异常记录》，当日上报项目经理。

6.4 回单与对账

回单当日交回客服组，按日期、伙食单位、订单号归档；客服组每周与采购人核对配送单、验收单和退换记录，按月编制结算清单，确保账单相符。

七、冷链配送专项

7.1 预冷

冷藏车、冷藏库和保温箱在使用前预冷至规定温度；热食、常温食材不得与冷藏冷冻食材混装；装车时快速作业，减少冷量流失。

7.2 装载要求

  1. 冷藏冷冻食材使用专用周转筐或托盘，不得直接接触车厢底板；
  2. 货物之间留有冷气循环空间，不得堵塞出风口；
  3. 不同类型食材分层、分区放置，生熟分开，防止交叉污染；
  4. 车厢门开启时间尽量缩短，装卸完毕立即关闭。

7.3 温度记录

冷藏车配置温度记录仪，每 5 分钟自动记录一次；驾驶员出车、装车、途中、交接各节点检查温度并记录；温度记录保存不少于 2 年，供采购人和监管部门查验。

7.4 断链处置

发现制冷设备故障或温度超出范围时：

  1. 立即将车辆停靠安全位置，检查故障原因；
  2. 可修复的，现场修复并降温至规定范围；
  3. 无法修复的，立即调派备用冷藏车接驳；
  4. 受影响食材单独存放、标识，经质检员评估合格后方可交付；
  5. 确认变质的，按不合格食材处置，不得配送；
  6. 及时向采购人报告处置情况，留存记录。

八、特殊场景保障

8.1 节假日保障

节前 5 日完成需求确认和货源储备，节前 3 日完成分拣预包装；节日期间安排值班人员和值班车辆，保持通信畅通，确保节日期间正常配送。

8.2 恶劣天气

遇暴雨、雷电、大雾、冰雪、高温等天气：

  • 提前查看天气预报，调整发车时间和线路；
  • 检查车辆制动、轮胎、灯光和防滑设施；
  • 降低车速、保持车距，必要时暂停行驶；
  • 提前通知收货单位，说明延误原因；
  • 必要时改用小型车辆或接力配送。

8.3 道路中断

遇道路施工、塌方、泥石流、交通管制等无法通行情况：

  1. 立即启动备选线路；
  2. 车辆无法通行但人员可通行的，组织人员徒步搬运；
  3. 协调当地供应商就近补货；
  4. 及时向采购人和部队报告，请求协助；
  5. 记录绕行里程、时间和费用，按合同处理。

8.4 车辆故障

驾驶员发现故障立即靠边停车、设置警示标志，报告调度员；调度员调派备用车辆和人员接驳，确保食材按时送达；短时间无法修复的，按《车辆管理制度》联系定点维修厂救援。

8.5 紧急加送

接到紧急加单后，客服组 5 分钟内确认需求，调度员 10 分钟内安排车辆和货源，配送员按最优线路送达；库存不足的，启动应急供应商或就近采购，确保部队需要。

8.6 部队移防与演训

接到部队移防、演训、抢险救灾等任务通知后，按《应对伴随保障方案》启动伴随保障，预置人员、车辆、货源和周转库，随部队行动实施跟进保障，任务结束后完成清点结算。

九、配送人员与车辆管理

9.1 人员管理

  1. 驾驶员、配送员持有效身份证、驾驶证、健康证上岗，按要求接受政审和保密教育；
  2. 统一着装、佩戴证件，举止文明，服从部队管理；
  3. 不得拍摄、传播部队营区、装备、人员和任务信息；
  4. 不得向无关人员透露配送点位、时间和品种数量；
  5. 每年组织健康体检，发现妨碍食品安全的疾病立即调离。

9.2 车辆管理

车辆执行《车辆管理制度》，重点落实：

  • 出车前晨检和收车后检查；
  • 定期保养、消毒和维修；
  • 专用车辆不得公车私用、不得搭载无关人员；
  • 车厢保持清洁、无异味、无污染；
  • 备用车辆保持良好状态，随时可调用。

9.3 行为规范

配送人员在营区内不得吸烟、饮酒、大声喧哗、乱扔垃圾；不得接受收货单位宴请、礼品；不得与收货人员发生争执，遇有争议及时报告项目部协调处理。

10.1 考核指标

客服组接到投诉后 30 分钟内响应，记录投诉人、时间、内容、涉及订单；一般问题 24 小时内处理完毕，复杂问题 3 个工作日内给出处理方案；处理结果书面反馈并回访确认。

10.3 回访改进

每周抽取不少于 30% 的配送点进行电话或现场回访，每月形成服务质量分析报告；对反复出现的问题，分析原因、制定措施、跟踪验证，实行闭环管理。

每月召开服务质量分析会，运用 PDCA 方法改进流程；每季度组织一次配送演练，检验应急响应、车辆调度、冷链保障和伴随保障能力；根据部队任务变化及时修订配送方案。

一、项目理解

1.1 项目背景

部队食品原料配送是后勤保障体系的重要组成部分，直接关系官兵饮食安全和部队战斗力生成。与普通社会餐饮配送相比，部队食材配送具有任务突发性强、保障点位分散、时效要求高、保密要求严、食品安全风险集中等特点。供应商必须把食品安全和保障时效放在首位，做到“平时看得出来、急时拉得出来、战时保得上去”。

本方案立足部队日常伙食保障和遂行军事行动任务伴随保障两类场景，对项目组织机构、服务流程、资源投入、质量控制、安全保密和监督考核作出整体安排，作为项目履约的纲领性文件。

1.2 项目特点

  1. 保障时效性强：部队任务变化快，订单确认、备货、配送、交接各环节均须压缩时限，紧急情况下须具备快速响应能力。
  2. 食品安全要求高：服务对象集中、就餐人数多，一旦发生食品安全问题影响面大，必须实行全过程、全批次、可追溯管理。
  3. 点位分散、批量不一：同一项目可能涉及多个伙食单位，配送地址、收货时间、品种规格各不相同，需要精细化调度。
  4. 保密要求严格：配送人员、车辆须进出部队营区或任务区域，涉及人员政审、保密教育、影像管控和车辆出入管理。
  5. 平战结合：日常配送与伴随保障须无缝切换，平时即按战时标准储备人员、车辆、货源和应急物资。

1.3 编制依据

  1. 《中华人民共和国食品安全法》《中华人民共和国农产品质量安全法》《中华人民共和国道路交通安全法》；
  2. 《食用农产品市场销售质量安全监督管理办法》《食品经营许可和备案管理办法》；
  3. GB 31605《食品安全国家标准 食品冷链物流卫生规范》及项目适用的食品安全国家标准；
  4. 招标文件、采购合同及采购人关于食品原料配送的各项要求；
  5. 我公司《车辆管理制度》《食材索证索赔方案》《应对伴随保障方案》及质量管理体系文件。

二、总体思路

按照“统一指挥、集中采购、分区仓储、专车专送、全程追溯、平战结合”的思路组织实施。

  1. 统一指挥：成立项目领导小组，实行项目经理负责制，对接部队后勤部门和各伙食单位，做到指令唯一、反应迅速。
  2. 集中采购：由采购组统一对供应商准入、比价、订单和结算进行管理，杜绝分散采购、随意采购。
  3. 分区仓储：按常温、冷藏、冷冻分区存放，按品类、批次、保质期实行标识管理，严格执行先进先出。
  4. 专车专送：项目车辆专用，驾驶员和配送员相对固定，实行双人双锁、全程温控和线路监控。
  5. 全程追溯：从供应商、采购批次、入库检验、库存流转到配送交接，形成完整记录，做到来源可查、去向可追、责任可究。
  6. 平战结合：日常配送与《应对伴随保障方案》衔接，预置应急人员、车辆、货源和通信手段，确保部队任务延伸时保障不断链。

三、项目组织机构

3.1 组织架构

  • 项目领导小组：由公司负责人、分管副总、财务负责人组成，负责重大事项决策、资源调配和应急指挥。
  • 项目部：设项目经理 1 名，下设采购组、质检组、仓储组、配送组、客服组、应急组。
  • 作业班组：采购员、验收员、质检员、仓管员、分拣员、调度员、驾驶员、配送员、客服专员。

四、岗位职责

4.1 项目经理

对项目履约负总责，负责与采购人对接、组织制定月度保障计划、调配人员车辆、处置突发事件、组织考核整改，确保食品安全、配送时效和服务质量达到合同要求。

4.2 食品安全员

负责食品安全日常管理，组织索证索票、进货查验、快速检测、留样、追溯和召回演练，对不合格食材行使拒收权，定期开展食品安全培训。

4.3 采购员

负责供应商日常联络、询价比价、下达订单、跟踪到货、处理缺货和规格不符问题，建立采购台账，不得私自更换供应商或变更采购渠道。

4.4 质检员

负责入库验收和出库复核，核对品名、规格、数量、产地、生产日期、保质期、检验检疫证明和外观质量，填写验收记录，对异常批次及时报告。

4.5 仓管员

负责分区分类存放、温湿度记录、先进先出、库存盘点和临期预警，确保账、物、卡一致，保持库房清洁、通风、防鼠防虫。

4.6 调度员

负责接收订单、编制配送计划、规划线路、安排车辆和人员，跟踪在途情况，处理临时加单、改单和车辆故障。

4.7 驾驶员与配送员

驾驶员负责车辆晨检、安全行车、温控设备运行和途中异常报告；配送员负责装车复核、交接验收、回单签收和现场服务。两人共同执行双人双锁制度。

4.8 客服专员

负责订单受理、需求确认、配送回访、投诉登记和转办，建立客户服务台账，定期汇总满意度信息。

五、服务流程

总体流程为：

订单接收 → 需求确认 → 采购备货 → 入库验收 → 检测留样 → 仓储养护 → 分拣复核 → 装车检查 → 冷链配送 → 交接验收 → 回单归档 → 对账结算 → 回访改进

5.1 订单接收与确认

客服组通过采购人指定渠道接收订单，核对品名、规格、数量、配送地址、收货时间、联系人及特殊要求；对模糊订单在 30 分钟内回访确认，形成书面订单记录。

5.2 采购与备货

采购组按订单组织货源，优先从准入供应商采购；对临时增加、规格变更的品种，启动缺货替代流程，替代品种须经采购人确认，不得擅自以次充好。

5.3 入库验收

质检组按照《食材索证索赔方案》查验供货凭证、检验检疫证明、质量检测报告和感官指标，必要时进行快速检测；验收合格后办理入库，不合格食材坚决拒收。

5.4 仓储与养护

仓管员按常温、冷藏、冷冻分区存放，离地离墙，标识批次和保质期；每日记录库房温湿度，定期盘点，对临期食材提前预警并优先出库。

5.5 分拣与复核

分拣员按伙食单位、品类、数量分拣，使用清洁消毒后的周转筐，防止交叉污染；复核员对品种、数量、规格、外观进行二次核对，粘贴配送标签。

5.6 装车与配送

配送组按“先卸后装、重不压轻、生熟分开、冷链优先”的原则装车，驾驶员检查车门、锁具、制冷设备和随车单据，按规划线路发车。

5.7 交接与回单

配送员与收货人当面清点品种、数量、规格，检查外观和温度，双方签字确认；异常情况填写现场记录并拍照留证，回单当日交回项目部归档。

5.8 对账与回访

客服组按合同约定周期与采购人核对订单、验收单和结算单，开具合规发票；配送后 24 小时内进行回访，记录质量、时效和服务意见。

七、食品安全与质量保障

7.1 供应商准入

供应商须具备营业执照、食品经营许可证或食品生产许可证、检验检疫证明等合法资质，经资料审核、现场考察和样品检验合格后进入合格供应商名录；每年复核一次，出现严重质量问题立即暂停或退出。

7.2 索证索票

按照《食材索证索赔方案》执行，定型包装食品查验生产许可编号、执行标准、生产日期和保质期；食用农产品查验产地证明、检疫检验合格证、检测报告和进货凭证；做到一批一证、票证相符。

7.3 进货查验

验收人员逐批核对品名、规格、数量、产地、生产日期、保质期、包装完整性、感官性状和运输温度，填写进货查验记录；发现腐败变质、霉变、异味、包装破损、货证不符的，坚决拒收并留存证据。

7.4 快速检测与抽检

质检组按计划开展农药残留、兽药残留、瘦肉精、吊白块、二氧化硫等项目快检，重点品种每日抽检，普通品种每周覆盖；快检异常批次立即封存、复检，必要时送第三方检测机构检测。

7.5 留样管理

对每批次重点食材进行留样，留样量不少于 125 克，专用容器、密封标识，冷藏保存 48 小时以上；发生疑似食品安全事件时，立即封存留样和同批次食材，配合调查。

7.6 追溯与召回

建立“供应商—采购批次—入库—库存—配送—伙食单位”追溯链条，记录保存期限不少于保质期满后 6 个月；接到召回通知或发现严重质量隐患时，2 小时内启动召回，24 小时内完成流向排查和回收。

7.7 不合格处置

不合格食材实行专区封存、红色标识、双人登记，按退货、销毁等方式处置，严禁回流餐桌；处置过程留存照片、视频和书面记录，并追溯供应商责任。

八、安全保密与部队管理

8.1 人员审查

进入部队营区或任务区域的人员须提供身份证明、健康证明和无犯罪记录证明，按采购人要求进行政审和备案；人员变动提前报备，未经审核不得进入。

8.2 保密教育

进场前组织保密教育，签订保密承诺书，明确不得拍摄、记录、传播部队营区、装备、人员、任务和配送点位信息；不得在微信、短视频平台发布相关内容和定位。

8.3 营区纪律

配送人员统一着装、佩戴证件，按指定路线和区域活动，服从哨兵和营区管理人员检查；不得擅自进入非配送区域，不得与无关人员谈论部队情况。

8.4 信息与影像管理

订单、点位、联系人等信息实行权限管理，纸质单据专柜保存，电子数据加密存储；车载监控和手机定位数据按采购人要求管理，不得外传。

8.5 车辆出入管理

车辆进出营区减速慢行、主动接受检查，按指定位置停放，装卸完毕及时驶离；车辆不得搭载无关人员，不得捎带违禁物品。

九、监督考核与服务承诺

9.1 内部考核

项目部实行日检查、周讲评、月考核，考核内容包括食品安全、配送准时率、品种准确率、冷链温度、服务态度、投诉处理和保密纪律；考核结果与绩效挂钩。

9.2 接受监督

主动接受采购人、部队后勤部门和市场监管部门的检查，如实提供台账、票据和检测记录；对提出的问题建立整改清单，明确责任人和完成时限，整改结果书面反馈。

9.3 服务承诺

  1. 所供食材符合国家食品安全标准和招标文件要求，不合格食材无条件退换；
  2. 按约定时间、地点、品种、数量完成配送，除不可抗力外不延误；
  3. 接到一般投诉 30 分钟内响应，24 小时内处理完毕并反馈；
  4. 因我方责任造成食品安全事故或配送延误的，承担相应赔偿责任；
  5. 严格执行保密规定，不泄露部队信息，不拍摄、不传播涉军内容。

应对伴随保障方案

2023-06-05

部队（人民武装部队）是党领导的人民武装力量的重要组成部分，担负维护国家政治安全和社会稳定、保障人民安居乐业的神圣使命，主要承担执勤、处突、反恐怖、海上维权、抢险救援、防卫作战等任务及拓展维护国家领土主权完整和国家安全职能。

当部队根据上级命令离开驻地营区赴异地遂行作战、战备、重大军事行动、抢险救灾和处置突发事件等军事行动任务时，通常要求“部队走到哪里，后勤保障就跟到哪里”。食品原料，作为后勤物资的重要组成部分，是部队战斗力生成的重要物质基础。供应商企业必须提高政治意识、责任意识和服务意识，按照“急事急办、特事特办”的要求，将食品原料配送工作主动融入部队后勤保障体系，接受部队统一指挥和调度，高效运作，无缝衔接，确保食品原料配送“供得上，保得了”，同时，要不断提高食品原料配送保障精确化、实时化水平，为部队“能打仗，打胜仗”作出应有贡献。

当部队遂行军事行动任务时食品原料配送应急管理机制

着眼部队遂行军事行动任务时提出的食品原料配送服务需求，供应商应立足战时需要，注重平战结合，加强平时应急训练与管理，确保“一声令下，能够拉得出、供得上”，保障部队“能打仗，打胜仗”。

开展供应保障任务预测

着眼部队遂行军事行动任务时食品原料配送保障需求，组建部队遂行军事行动任务食品原料伴随保障应急管理服务团队，坚持“建在平时，用在战时”，并开展食品供应保障任务预测，做到预有准备。供应商开展食品原料配送保障任务预测时，应根据部队军事行动任务性质、任务方向或地区、兵力编成等因素，科学预测食品原料供应保障方式、可能需求量、配送服务力量规模等。

前送保障

通常情况下，当部队在距离驻地营区较近的方向或地区遂行军事行动任务时，如100公里范围内，可采取前送保障方式对部队进行食品原料配送服务保障，即按照从公司总部直接配送至部队各作战单位（伙食单位）的方式进行配送服务。前送保障方式主要具有以下特点：

一是部队遂行任务地区与部队营区驻地（成都市区）相对较近，加之成都市周边交通发达，可通过调整运输配送时间及时送达所需食品原料。

二是成都市区食品原料供应市场发达，公司在成都地区具有较稳定的食品原料采购供应渠道，可较好地保障部队遂行军事行动任务期间对食品原料的采购配送需求；

三是前送保障流程及管理与平时配送服务流程及管理大致相同，不需要作大的调整，可保证前送保障稳定运行。

伴随保障

通常情况下，当部队在远离驻地营区的方向或地区遂行军事行动任务时，如超出100公里范围内，前送保障方式已明显不能满足部队对配送服务时效性的要求或前送保障综合运输配送成本明显过高时，应采取伴随保障方式对部队实施食品原料供应保障。伴随保障方式主要具有以下特点：

一是“部队走到哪里，配送服务就跟到哪里”，可对部队及各个作战单元实施“零距离”贴身跟踪保障，具有极高的配送服务时效性，可做好“随要随到”。

二是需在部队遂行军事行动任务的方向或地区重新开发和搭建食品原料供应保障渠道，以满足部队及各个作战单位（伙食单位）的多样性需求。

食品原料配送管理

1、原则上按照从野战食品原料库房直接配送至各作战单元（伙食单位）的方式进行配送服务；

2、配送组按照各作战单元（伙食单位）要求的配送时间节点，提前勘察和规划运输配送线路，科学预计在途运输时间，做到提前出发、准时到达部队指定的配送地点；

3、建立临时通信联络保障和沟通协调机制，随时掌握各作战单元（伙食单位）配送需求信息，随时调整应急配送方案和计划，确保配送服务不间断；

4、若部队遂行任务地区或至各作战单元（伙食单位）的途径地区遭遇暴雨雷电天气、洪涝、泥石流、地震等自然灾害，立即启动应急预案，派出先遣组，提前勘察和规划好配送车队行进路线，提前出发或绕行，保证配送车辆按时到达。

5、若配送车辆在途中发生故障或交通事故，立即启动应急预案，派应急备用车和配送人员以及救援设备立即赶赴故障地点，做好对接工作，保证将食品原料安全按时送往各作战单元（伙食单位）。

6、若遇道路中断车辆无法通行，只能人员通行，则伴随保障组应组织方便面、牛奶、面包、矿泉水等食品人力送到各作战单元（伙食单位），保证官兵正常就餐。

7、若配送驾驶员或搬运工有特殊情况无法正常车出车，由应急采购配送人员和应急配送车辆接替配送工作，保证按时配送到位。

三、持本人如有变动或遇特殊情况部门负责人应当在查看加油清单后再另行安排专人保管。

四、每月19日前, 行政部分管领导查看行政部所有车辆加油清单并预分配油本金额开具增值税发票。

五、每月19日下午分管负责人查看、记录各车行程计算百公里油耗。经领导审批后月底公布油耗情况并进行相关奖惩。

*（4）备用车调用*

一、需要备用车的送货组于当日装车前向行政部负责人汇报指定专人核实用车情况派遣车辆。

二、公司用车由分管领导批准行政部安排车辆不得延误工作。

三、非本车驾驶员驾驶备用车辆的出车前做好交接手续。

四、机动车使用完毕后将车辆内、外清洗干净停放于指定位置。

*（5）车辆事故处理*

一、交通事故发生后随车人员应保护车上货物的安全立即通知行政部负责人或车辆分管领导。负责人或分管领导接到报告后迅速赶往现场进行处理。

二、有人员受伤先救治伤员保护现场同时通知交管部门和保险公司进行现场勘察。

三、根据责任裁定如超出保险理赔范围的由驾驶员负责赔偿。

四、事故处理完毕后行政部做好事故记录做相应处理。

*（6）车辆卫生*

一、送货回来后要清洗车辆保持车辆出车前干净整洁。

二、当天没有擦洗的向部门负责人说明情况次日出车前清洗完毕。

三、每周至少对车辆内部、机器擦洗一次。车内、外清洗干净后要擦试干防止生锈或电线短路。内部机器要擦拭干净保证机器的正常运转。

四、行政部负责人随时抽查车辆卫生。

五、值班驾驶员负责洗车场卫生、洗车用具的清洗、维护、保管。行政部负责指定洗车用具的摆放位置。

*（7）车辆内外消毒*

除了日常清洗，定期消毒也是车辆清洗消毒制度中重要的一环。下面是定期消毒的步骤：

  1. 使用含有效成分的消毒剂，如酒精溶液，喷洒在车辆内外表面；
  2. 确保消毒剂能够覆盖到车辆各个角落和表面；
  3. 让消毒剂在车辆表面停留一定时间，以确保杀灭细菌和病毒；
  4. 使用干净的湿布或纸巾擦拭车辆表面，清除残留的消毒剂。

*（8）双人双锁制度*

我公司车辆出发前，后备箱锁好，每辆车配置一名驾驶员、一名配送员，两人相互监督，两人一起才能打开运送车厢，保障食材在运输过程中的质量。

*（9）车辆维护*

一、日常保养

1、车辆行程3000—5000公里每季度进行一次二级维护更换三滤。

2、新车按照《新车保养手册》在指定维修厂维护、保养。

3、司机做好保养记录。

二、大修维护

1、车辆大修后2000公里内行驶速度不得超过80公里/小时出车前必须预热5—10分钟。

2、大修后的车辆按照大修维护要求行程1500—2000公里保养1次更换三滤；5000公里再更换三滤1次。

3、行政部做好大修维护记录。

4、不按规定调修和保养的发生故障由行政部鉴定原因驾驶员承担全部责任。

*（10）车辆修理*

一、严格按照修车审批制度坚持先审批后修车、购件的原则。

二、修车时须持行政部分管领导签字的《车辆派修单》到公司定点维修厂修理。

三、行政部分管领导根据《车辆派修单》内容安排。检查、维修车辆故障。

四、维修项目以《车辆派修单》填写的维修项目为准司机试车满意后根据《维修明细单》与维修厂核对替换下的旧件并报行政部分管人查验。

五、如补胎、配钥匙等小金额的维修项目于每周周三集中报销。

六、行政部外出车辆在途中发生故障拨打行政部负责人和定点修理厂求助电话要求派人修理。

七、行政部负责人在10分钟内对求助车辆给予答复。

八、对故障车辆进行应急补救后及时与送货车辆跟踪询问补救结果及运行情况。

九、送货车在外发生故障需在非定点维修的向车辆分管领导报告维修费用进行请示并开具正规发票和与发票相符的维修明细单。回到行政部后补办相关手续。

十、维修项目只限于应急补救的维修项目不得擅自维修其他项目。在外维修替换下的旧配件必须与维修明细相符并交行政部分管负责人进行回收登记。

*（11）车辆检查*

结合车辆的保养、维修情况，由驾驶员采购日常定期与不定期方式对车辆进行安全检查，及时发现车辆安全隐患，预防事故的发生，保证行车安全。

1、日常车辆安全检查项目

1）检查车辆整体外观，有无划痕、剐蹭情况；

2）检查车辆日常清洁卫生，安全设施情况；

3）检查车辆发动机系统工作情况，查看是否有漏油、水、电、气等现象；

4）检查底盘系统、刹车系统、灯光照明系统工作是否有效、齐全；

5)特种车辆（冷链车）检查制冷相关设备的情况。

2、出车前后检查

1）检查车辆有各种有效证件是否齐全，保险是否有效，驾驶员随车携带驾驶证件；

2）检查车辆外观整体情况；

3）检查车辆油、电、气、灯光是否正常，安全设施是否齐全，制动是滞灵敏；

4）返回后检查车辆的完好状况；

5）离开前检查车辆电源、手刹、门窗是否关闭，是否停于指定位置。

*（12）安全行车规范*

1、驾驶员树立公对公司财产和他人生命高度负责的精神，将安全行车放在第一位，谨慎驾驶，严格遵守道路交通规则。

2、保持车辆完好状态，驾驶过程中发现不安全隐患及时处理，确保各部机件牢固、灵敏，制动有效；

3、禁止使用公司车辆练车，不断提高驾车技术，能在复杂的路面及恶劣气候条件下安全驾驶；

4、在驾驶过程中，驾驶员要做到不超载超限、不超速行车、不强行超车、不开带病车、不开情绪车、不开急躁车、不开冒险车、不酒后开车；

*（13）车辆保险*

公司所有车辆由公司统一办理保险，一旦出现车辆保险索赔事件，车辆驾驶员第一时间与公司取得联系，做好现场的图片、影像的留存处理，由公司专人与保险公司沟通，配合保存好索赔资料并跟进车辆保险理赔相关事宜。

*（14）车辆违章、事故处理*

1、车辆行车过程中出现的违章考核和扣分，以谁违章谁承担的原则进行处理。综合部不定时对车辆的违章情况进行查询，并督促违章人员进行处理；

2、车辆驾驶过程中，驾驶员和随车人员须保证手机畅通，出现交通事故后必须告知部门负责人、车险负责人及公司领导，第一时间通知交警部门并保险报案，留取事故现场的图片及影像，保护好现场，有人员伤亡第一时间拨打120抢救伤员；

3、发生交通事故，在行车肇事责任判明后，事故所发生的医疗费、拖车费和维修费等费用在保险公司理赔后的余额按以下原则处理，驾驶员协助及跟进理赔相关事宜。

*（15）违反车辆规定考核标准*

1、未经允许擅自使用车辆，一经查实给予综合部车辆管理人员以200元/次处罚，擅自使用车辆人员300元/次处罚；

2、在加油、维修费等方面弄虚作假的，一经查实，最低处以虚报金额的双倍处罚，情节严重者解除劳动合同；

3、公车私用的人员一经查实，给予用车人员200元/次处罚；

4、未经允许擅自使用车辆或公车私用，发生交通事故，所有责任由用车人自行承担，并处以500元/次处罚，情节严重的解除劳动合同。

*（16）监督检查制度*

一、监督检查从业驾驶人员的资质

（1）监督检查驾驶人员的聘用审核和安全生产管理情况，检查驾驶员管理基础档案实行“一人一档”情况，检查对违章和事故驾驶员处理情况。

（2）监督检查驾驶员严重违法行为的处理情况和记分管理情况，要对情节严重、素质差，安全意识不强经常出事故的驾驶人员进行解聘，优化驾驶人员队伍，提高驾驶员整体素质。

（3）监督检查对于超速、超载、疲劳、酒后驾驶等违法行为情节严重的驾驶人员予以解聘的情况。

二、监督检查安全基础工作及宣传教育培训

监督检查驾驶员的持证上岗情况和其他人员的教育培训情况，以及安全宣传、劳动组织、用工等情况。

三、监督检查应急机构和应急队伍建设

建立和完善运输安全事故的预防、预警、预报应急机制情况。

*（17）驾驶人员安全管理制度*

驾驶员应是作风正派，组织纪律性强，身体健康的从业人员。

驾驶员必须领取驾驶证、从业资格证，方可驾驶车辆。

驾驶员的正常培训由本人负责，定期培训由本道路运输经营者安全生产管理部门组织实施。

发生不安全情况，应及时报告本道路运输经营者安全生产管理部门，不准隐瞒事故真相，并积极配合事故的处理。

驾驶员应服从调度，按照规定路线行驶，连续行车不准超过4小时，杜绝各种违章行为。

驾驶员要认真做好车辆日常维护工作，保持车容整洁、文明驾驶，严格遵守交通规则，树立良好的职业道德。

车辆正常出车前，应将文明卫生与安全工作结合检查。

驾驶员必须遵守下列规定：

①驾驶营运车辆时，须携带驾驶证、行车证、道路运输证、从业资格证等其它证件。

②不准转借、涂改和伪造驾驶证、行车证、道路运输证、从业资格证等其它证件。

③不准将营运车辆交给没有驾驶证和从业资格证的人驾驶。

④不准驾驶与驾驶证、从业资格证车型不相符合的车辆。

⑤未按规定审验或审验不合格的，不准继续驾

⑥饮酒后不准驾驶车辆。

⑦不准驾驶安全设备不全或机件失灵的车辆。⑧不准驾驶不符合装载规定的车辆。

⑨患有妨碍安全行车的疾病或者过度疲劳时，不准驾驶车辆。

⑩驾驶车辆时不准吸烟、饮食、闲谈、打手机或其它妨碍安全行车的行为。

*（18）驾驶人员培训制度*

一、培训的目的

依据公司相关管理制度及本项目的要求，对公司所属驾驶员进行职业素质及技能培训，以提高驾驶员业务能力，增强我司驾驶员爱岗敬业的服务意识，满足服务质量工作要求。

二、培训范围

本制度适用于公司汽车物流事业部所有驾驶员。

三、职责

由事业部协调督导安全、技术、调度、客服、统计、财务等职能部门对驾驶员进行相关对口教育培训。

四、培训形式及时间

1、岗前培训：对于新招聘的驾驶员进行零散培训，时间根据实际情况而定，在上岗前完成相关培训工作。

2、例会学习：由行车安全处车务人员统一安排日期，时间为每月第一周和第三周具体日期由根据自身实际情况自定，并将培训情况按要求填写例会学习反馈表，上报经理处。

3、重点教育：由事业部牵头，协调运营、客服、车务、安全、技术等部门针对公司当月发生的重大交通、质损事故等方面内容进行重点教育，具体日期及培训方式根据实际情况而定，但每月不能少于一次。

五、培训内容

1、新招聘驾驶员的岗前培训由总部行车安全处负责，其培训内容为：

（1）公司的质量方针、质量目标。

（2）驾驶员守则和岗位责任制。

（3）有关的服务规范、服务提供规范、质量控制规范。

2、在岗驾驶员的常规培训由各场站车务人员负责，行车安全处负责督导，其培训内容为：

（1）行业动态、法律法规知识。

（2）货物生产厂家装、卸车操作规范。

（3）安全行车常识、事故案例分析。

（4）车辆故障判断、维修保养、技术知识。

3、违规、违纪驾驶员的重点教育由行车安全处负责，车务人员支持配合协助，其培训内容为：

（1）法律法规；

（2）实例剖析；

（3）遵章守纪意义；

（4）违法违规后果；

六、工作程序

1、由公司行政处人员编制年度培训计划，经部门经理审核报领导批准后实施。

2、根据年度培训计划组织、实施；培训时间、地点由实施部门自定，并须提前通知接受培训驾驶员。

4、主讲人应提前备课、按时授课，保证质量。

5、因故不能按时参加培训的驾驶员必须填写请假单，经车务人员批准后方可休假。

6、未按时参加培训的，必须进行补课。

7、培训结束后，实施部门应对受训驾驶员进行考核，全面掌握培训效果。

8、实施部门应对培训过程建立培训记录，并存档保管。

9、本制度纳入管理人员绩效考核内容。

七、管理规定

1、遇雨、雪、雾等特殊天气，根据实际情况可适当推迟教育培训学习时间，具体推迟时间以公司通知为准，除非因不可抗力（地震、洪水、疫情等因素），不准取消教育培训学习。

2、驾驶员必须严格遵守教育培训学习的请假规定

（1）请假理由

a.本人或直系亲属的婚、丧、嫁、娶、大病等，并提供相关证明。

b.车辆事故、突发事件，并提供相关证明。

（2）请假时间

每次例会或培训学习前30分钟，超时请假一律无效。

（3）请假形式

须请假的驾驶员本人打电话或书面申请，由车务管理人员填写《驾驶员例会学习请假单》，在规定时间内上报行车安全处，他人不准代请。

（4）请假控制率：场站总车数的3%，由场站车务人员掌握，超出部分一律无效。

（5）未按规定请假的驾驶员，一律按迟到或旷会进行处理。

（6）重点教育学习必须由重点驾驶员本人参加，其他人不得代替，否则视为旷会。

3、会场纪律

（1）会议前20分钟，驾驶员持本人例会学习卡到学习地点开始签到。

（2）会议开始后进行点名，被点到的驾驶员须大声答到并举手示意。

（3）遵守会场秩序，不准交头接耳、大声喧哗、任意走动。

（4）保持会场卫生，不准吸烟、随地吐痰、乱扔废弃物。

（5）爱护公共设施，不准乱刻乱划、任意涂写。

（6）认真听讲，不准打瞌睡、玩手机或电子游戏、翻看书报杂志。

4、迟到和旷会的界定

（1）例会开始5分钟到会者视为迟到。

（2）例会开始后超过5分钟到会者视为旷会。

（3）迟到与旷会的驾驶员必须接受处罚。

5、补会

（1）旷会和请假的驾驶员须在公司行车安全处指定的时间、地点进行补会，具体日期由行车安全处提前通知。

（2）被处罚的驾驶员直接从公司财务挂账扣款，驾驶员书面检查到行车安全处登记、销案。

6、驾驶员的健康体检

（1）定期、定点医院全面对驾驶员健康体检普查。

（2）把驾驶员体检情况备案，存入驾驶员档案。

（3）驾驶员健康体检中，发现有不适驾驶车辆疾病的驾驶员根据情况劝退离职。

八、处分规定

1、管理人员

（1）不按时组织驾驶员例会学习培训扣发当月全额绩效工资，累计3次者事业部将给予除名。

（2）虽组织了驾驶员例会学习，但走形式、敷衍了事、会场秩序混乱、组织无序，达不到预期培训效果的，扣发当月绩效工资50%做为处罚。
